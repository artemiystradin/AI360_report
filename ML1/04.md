## Метод инерции (Momentum)

$w^{(0)}$ - инциализация
$h_0 = 0$ - вектор инерции
Шаг: $\begin{cases} h_k = \alpha h_{k-1} + \eta \nabla_w Q(w^{(k-1)})\\ w^{(k)} = w^{(k-1)} - h_k \end{cases}$
(вместо градинета можно использовать любый другие оценки (как в SAG итд))

## Адаптивный шаг (AdaGrad)
**Прблема:** веса обновля.тся по-разному и некоторые веса мы можем начать обновлять очень поздно, пока остальные уже много раз обновлены
**Решение:** давайте размер шага будет свой для каждого веса

$G_{0_j} = 0$
$G_{k_j} = G_{k-1_j} + (\nabla Q(w^{(k-1)}))^2_j$
$w_j^{(k)} = w^{(k-1)}_j - \frac{\eta k}{\sqrt{G_{k_j} + \varepsilon}} (\nabla Q(w^{(k-1)}))_j$
По j-му параметру на k-м шаге мы шагаем по градиентуЮ но мы домножаем на длину шага, деленную на то, сколько мы наобновляли этот вес и если мы редко его обновляли, то коэф. будет больше.

**Проблема:** $G_{k_j}$ только растет и может быстро задавить оптимизацию
**Модцификация:** RMSProp
(\*) $G_{k_j} = \alpha G_{k-1_j} + (1-\alpha)(\nabla Q(w^{(k-1)}))^2_j,\ \alpha \in (0, 1)$


## Adam = Momentum + AdaGrad

# Регуляризация

**Известный экспериментальный факт:**
Линейная модель переобучена <=> большие веса

### Почему? (интуиция)
#### Объяснение 1
  Пусть есть линейно зависимые признкаи
  $\exists v \in \mathbb{R}^d : \forall x \in \mathbb{X} \langle v, x \rangle = 0$ 
  $w_*$ - решение
  Тогда $\langle w_* + \alpha v, x\rangle = \langle w_*, x\rangle + \alpha\langle v, x \rangle [=0] = \langle w_*, x\rangle$
  т.е. $w_* + \alpha v$ - решение ($\forall \alpha$)
#### Объяснение 2
  $a(x) = 10^8 \cdot \text{площадь} - 10^9 \cdot \text{этаж} + \dots$
  $10^8\cdot(\text{площадь} + 0.001) = 10^8\cdot\text{площадь} + 10^5$
  Большие веса => гиперчувствительность к изменениям в признкакх (даже очень маленьким)


**Идея:** Запретить большие веса
$Q(w) + \alpha R(w) \rightarrow \min$ 
$R(w)$ - регуяризатор
**Примеры:**
- $R(w) = ||w||^2_2$ - $L_2$-регуляризатор
- $R(w) = ||w||_1$ - $L_1$-регуляризатор
$\alpha$ - коэф. регуляризации ($\alpha >> 1 \Rightarrow w_* = 0$)
$\alpha$ нельзя подбирать по обучающей выборке (гиперпараметр)

#### Стратегии подбора $\alpha$
- Grid Search (Перебор по порядку (по возрастанию линейно/логарифмически...))
- Random Search (Рандомно перебираем)
- AutoML

Нейминг:  
1) $\frac1l \sum ^l_{i=1}(\langle w, x_i\rangle - y_i)^2 + \alpha||w||^2_2 \to \min$ - Ridge-регрессия
2) $\frac1l \sum ^l_{i=1}(\langle w, x_i\rangle - y_i)^2 + \alpha||w||_1 \to \min$ - LASSO-регрессия


### Замечание 1
Иногда свободный коэф должен быть большим чтобы сравнять масштаб, поэтому:
**ВАЖНО!** не включать $w_0$ в регуляризацию

### Замечание 2
Пусть есть признаки разных масштабов
Тогда мы можем за одни веса штрафовать сильно больше других просто за то, что они стоят у признаков другого масштаба => надо масштабировать признаки, если хотим регуляризацию

### Замечание 3
Добавление регуляризатора ускоряет град. спуск (т.к. она упрощает рельеф)
Масштабирование тоже!!

## Разреженные модели
Пусть мы знаем, что модель должна зависеть не от всех признаков (часть весов - 0)
1) Накидали в признаки все подряд
2) Ускорение моделей
3) $N << p$
   $l << d$
### Решение для линейных моделей: $L_1$ регуляризация
$Q(w) + \lambda ||w||_1 \to \min_w$
#### Объяснения:
1) $\Leftrightarrow \begin{cases} Q(w)\to min_w \\ ||w||_1 \le C\end{cases}$ Дальше там если нарисовать условие, то это ромбики => велика вероятность, что линия уровня Q пройдет через вершинку (где часть весов 0)
2) С точки зрения $L_1$ регуляризации не важно, какой вес приближать к 0:
   $w = (1, \varepsilon), 0 < \delta < \varepsilon << 1$
   $|w - (0, \delta)|_1 = 1 - \delta + \varepsilon = |w - (\delta, 0)|_1$
3) Проксимальный метод - очень хорошо минимизирует функционалы с диффиринцируемой и выпуклой частями 
   (ошибка - дифференцируема, регуляризатор - выпуклый)
