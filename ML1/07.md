# Методы классификации

## Логистическая регрессия
Хотим оценить вероятности классов (уверенность модели в своем ответе)

**(!)** a(x) = 1 - Модель уверена в ответе на 80% ощначает, что если взять все объекты с этой уверенностью, то 80% из них будут иметь y = 1

### Зачем нам это?
1) b(x) - вероятность того, что клиент уйдет
   Звоним, если $b(x) \ge 0.9$. Среди них $\le 10\%$ не уходят
2) Если знаем вероятность того, что будет клик по рекламе и знаем сколько нам заплатят, можем решить нужно ли выставлять эту рекламу

### Формализация
b(x) - вероятность положительного класса
Считаем ее, как $\sigma(a(x))$, $\sigma$ переводит вещественную прямую в $[0, 1]$ 

b(x) корректно оценивает вероятности, если для вероятности p среди всех объектов $x\in X$ с $b(x) = p$ доля положительных равна p

Пусть все элементы одинаковые. Тогда заметим, что такое требование:
$$argmin_{b\in[0, 1]} \mathbb{E}(L(y, b)|x) = p(y = 1|x), n \to \infty$$
работает всегда (рукомахательно):
Пусть у нас есть n объектов с похожими прогнощами, значит модель стремиться на них выдать корректную вероятность

#### Для каких L(y, z) выполнено это условие
MSE : $L(y, z) = (y - z)^2$ 
$\mathbb{E}_y(b-[y=1])^2 = p(y=1|x)(b-1)^2$
$\frac{\partial}{\partial b} = -2p + 2b \Rightarrow b = p$
т.е. MSE будет пытаться корректно оценивать вероятности
(!) Но это плохая идея:
$\frac1l\sum^l_{i=1}(\sigma(\langle w, x_i\rangle)-[y_i=1])^2 \to \min_w$
Тогда градиент на $-\infty$ будет близок к 0 и мы оттуда не выберемся

Для модуля не работает

Пусть каждый ответ $y_i$ это случайная величина с распределением бернулли.
b(x) - оценка вероятности $p(y_i = 1|x)$ 
Запишем правдоподобие:
$$\prod^l_{i=1}b(x_i)^{[y_i=1]}(1-b(x_i))^{[y_i=-1]} \to max_b$$
$$\sum^l_{i=1}(-[y_i=1] \log b(x_i) - [y_i=-1] \log(1-b(x_i))) - \log loss$$
Для log-loss требование выполнено.
Тогда $L(y, z) = \log(1 + e^{-yz})$  - логистическая функция потерь.
