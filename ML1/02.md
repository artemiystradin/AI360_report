# Линейная регрессия
## (1) Как устроено
- $\mathbb{Y} = \mathbb{R}$
- $\mathbb{X} = \mathbb{R}^d$
- $x = (x_1, \dots x_d)$
- $a(x) = w_0 + \sum_{j=1}^d w_jx_j$
	- $w_0$ - свободный коэффициент, bias, intercept
	- $w_j$ - веса

Предположение: есть константный признак 
(Например пусть $x_1 = 1$ (если что, добавим))
Тогда можем забить на $w_0$ и $a(x) = (w, x), w = (w_1, \dots w_d), x = (x_1, \dots x_d)$

## (2) Применимость линейных моделей
1. Признаки независимы
2. Признаки влияют на прогноз линейно
#### Вывод:
Для линейных моделей данные надо готовить!!!

## (2.1) Категориальные признкаи
$x_j \in \{c_1, \dots c_m\}$ (Например район)
### Решение:
#### One-hot-encoding:
$x_j \rightarrow b_1(x_j), b_2(x_j), \dots b_n(x_j), b(x_j) = [x_j = c_i]$
(Буквально заменяем $x_j$ на набор битов-индикаторов)
Есть еще one-cold-encoding, это наоборот все 1 кроме одного 0.

## (3) Измерение ошибки в задачах регрессии

### MSE
- $L(y, z) = (y-z)^2$
- $Q(a, X) = \frac{1}{l}\sum_{i=1}^l (a(x_i) - y_i)^2$
- !!! Ошибка в других единицах измерения -> RMSE (стоит взять корень)
- Хорошо для сравнения моделей, но плохо показывает насколько все хорошо

### Коэффициент детерминации
#### $R^2 = 1 - \frac{\sum_{i=1}^l(a(x_i) - y_i)^2}{\sum_{i=1}^l (y_i-\overline y)^2}$
- $a(x_i) = y_i \Rightarrow R^2=1$
- $a(x_i) = \overline y \Rightarrow R^2 = 0$

### MAE
$L(y, z) = |y-z|$
$MAE = \frac{1}{l}\sum |a(x_i) - y_i|$


(!!) MSE стимулирует подгонку под выбросы (если есть выбросы с большой ошибкой, то модель будет сильнее стараться их загладить),
A MAE лучше их игнорирует.

Почему тогда всегда не использовать MAE:
1. Может быть правильно штрафовать за большие ошибки
2. В MSE по производной можно понять насколько далеко мы от минимума. 
   (У MAE она всегда $\pm 1$)
   ![[Pasted image 20260409225842.png]]

### Huber loss
$L_\delta(y, z) = \begin{cases}\frac{1}{2}(y-z)^2, |y-z| < \delta\\ \delta(|y-z| - \frac{1}{2} \delta), |y-z|\ge \delta\end{cases}$
Лучшее от MAE и MSE: маленькая ошибка при выбросах, маленькая производная в окрестности минимума 
Но есть проблема со второй производной
#### Решение:
Log-Cosh:
$L(y, z) = \log(ch(|y-z|))$ - вторая производная непрерывна.

### MSLE 
$L(y,z) = \log(z+1) - \log(y+1)$

### Относительная функция потерь
$L(y, z) = |\frac{y-z}{y}|$
$MAPE = \frac{1}{l}\sum|\frac{y_i-a(x_i)}{y_i}|$
- Интерпретируемость
- Хороши при разных масштабах целевой переменной

### Квантильная функция потерь
$L(y z) = (\tau-1)[y-z < 0](y-z) + \tau[y-z \ge 0](y-z)$
С помощью $\tau$ определяем что для нас страшнее (занизить или завысить прогноз)
