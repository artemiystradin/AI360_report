# Линейная классификация
Если класса 2, можно сделать  $a(x) = sign\langle w, x\rangle$
$|\langle w, x\rangle|$ - "уверенность"

$Q(a) = \frac{1}{l}\sum^l_{i=1}[a(x_i) \neq y_i]$
$Q(a) \to \min_w$ 
**(!!!)** Но это не обучить, т.к. недиффиринцируемо

$Q(a) = \frac1l \sum^l_{i=1}[sign(\langle w, x_i\rangle) \neq y_i] = \frac1l\sum^l_{i=1} [y_i\langle w, x_i\rangle < 0]$

$M_i = y_i\langle w, x_i \rangle$ - отступ
$sign(M_i)$ - корректность классификации
$|M_i|$ - уверенность

Т.е. пока используем такую функцию потерь:
$L(M) = [M < 0]$ - пороговая ф.п.

### **Идея**: заменить $[M < 0] \le L^*(M)$

$0 \le \frac1l \sum^l_{i=1} [y_i\langle w, x_i\rangle < 0] \le \frac{1}{l}\sum^l_{i=1} L^*(y_i\langle w, x_i\rangle) \to \min$

#### Варианты:
1) $L_1^*(M) = \max(0, 1-M)$ - hinge loss
2) $L_2^*(M) = \log(1 + \exp(-M))$
3) $L_3^*(M) = e^{_M}$
4) ...
