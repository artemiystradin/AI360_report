k-й класс: $TP_k, FP_k, FN_k, TN_k$
Для отделения k-го класса от остальных

| Микро-Усреднение                                                  | Макро-Усреднение                               |
| ----------------------------------------------------------------- | ---------------------------------------------- |
| $\overline{TP} = \frac 1k \sum^k_{i=1} TP_k$                      | $precision_k = \frac{TP_k}{TP_k + FP_k}$       |
| $precision = \frac{\overline{TP}}{\overline{TP} + \overline{FP}}$ | $precision = \frac 1k \sum^k_{i=1}precision_k$ |
| Больше влияние крупных классов                                    | Все классы имеют одинаковый вклад              |

# Решающие деревья
Линейные модели дифференцируемы, поэтому их можно обучать градентными методами
Но не все задачи дифференцируемы :(

## Решающее дерево - бинарное дерево, где:
1) v - не лист => $\beta_v : \mathbb{X} \to \{0, 1\}$ (то в ней лежит предикат)
2) если v - лист, то $c_v \in \mathbb{Y}$ прогноз

Бывают multi-way деревья, но это очень затрастно и возможно переобучение.

## Какие бывают предикаты
1) $\beta_v(x) : [x_j \ge t]$
2) $\beta_v(x) : [\langle w, x\rangle \ge t]$
3) $\beta_v(x): [p\rho(x, x_0) \ge t]$

## Обучение деревьев
**Гипотеза:** Если из всех корректных на $X$ деревьев взять самое маленькое (по глубине, числу вершин итд), то оно не будет переобучено
(Не выйдет, NP-трудная)
Тогда порешаем жадно

```
SplitNode(m :[вершина], R_m :[Объекты, дошедшие до этой вершины]):
	if критерий останова:
		c_m = | Среднее по всем обхектам
		      | Самый частый класс
		      | ...
	j, t = arg max_(j = 1,..k, t\in R) Q(R_m, j, t))
	^
	|-Перебором j и t
	R_l = {(x, y) \in R_m | [x_j < t] = 1}
	R_r = {(x, y) \in R_m | [x_j >= t] = 1}
	SplitNode(l, R_l)
	SplitNode(r, R_r)
```
### Критерий останова:
- Макс. глубина
- Мин. число объектов
- ...
### Критерии качества предиката
H(R) - impurity (хаотичность) показывает разнородность ответов в R
1) регрессия: $H(R_m) = \frac{1}{R_m} \sum_{(x_i, y_i) \in R_m} (y_i-\overline y)^2$
2) Классификация: $H(R) = \sum p_k(1-p_k)$
#### Общий подход:
$$H(R) = \min_{c\in \mathbb{Y}}\frac{1}{|R|}\sum L(y_i, c)$$Ошибка лучшего константоного предположения
Если ошибка получается маленькой, то impurity небольшое
$$Q(R_m, j, t) = H(R_m) - \frac{|R_l|}{|R_m|} H(R_l) - \frac{|R_r|}{|R_m|} H(R_r)$$(!) Важно отметить, что без нормировки, то мы получим дерево, которое просто на каждом шаге отрезает по 1 объекту, а так такие мувы штрафуются
